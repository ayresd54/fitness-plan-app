# Fitness Plan App

A personalized fitness, nutrition, and lifestyle planning app built with React.  
The app generates workouts, macros, milestones, and progress tracking based on user input.

---

## 🚀 Features

### 🔹 Setup Wizard
Collects:
- Name
- Age
- Gender
- Height
- Current weight
- Target weight
- Target date

### 🔹 Automatic Calculations
- TDEE
- Daily calories
- Protein / carbs / fats
- Weekly fat‑loss rate
- Total timeline

### 🔹 Workouts
- Phase 1 (foundation)
- Phase 2 (progressive overload)
- Gender‑aware templates

### 🔹 Nutrition
- Daily calories
- Macro breakdown
- Guidance

### 🔹 Progress Tracking
- Add entries
- Notes
- Delete entries
- Sorted by date

### 🔹 Lifestyle Milestones
- Weekly habits
- Gender‑specific habits
- Progressive difficulty
